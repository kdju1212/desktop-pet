펫 설정
이미지나 HTML 파일은 이 앱 폴더 안에 넣어두면 됩니다.
1000ms가 1초입니다. 예: 3000은 3초.
AI 서비스 키 입력 (쉬운 설정)
아래 서비스 중 하나에 가입해서 키만 붙여넣으면 됩니다. 여러 개 넣으면 하나가 안 될 때 자동으로 다음 걸로 넘어갑니다. 엔드포인트/모델 이름은 몰라도 되고, Gemini처럼 화면 인식이 가능한 서비스는 같은 키로 화면 캡처 AI 도움도 자동으로 됩니다.
직접 입력 (고급, 선택 사항)
화면 캡처 AI 도움은 이미지를 인식할 수 있는(Vision) 모델이 필요합니다. 같은 API 키/엔드포인트로 Vision을 지원하는 모델 이름이 있다면 위 "Vision 모델"에 적어두세요 — 별도의 키 없이 화면 캡처 도움에 그 모델이 자동으로 쓰입니다.
API 키는 OS 자격 증명 저장소로 암호화되어 settings.json에 저장됩니다. 혼자 쓰는 앱 기준으로만 사용하세요.
켜면 할일/데일리 할일이 이 서버에 저장되고, 로컬 schedule.json은 더 이상 쓰이지 않습니다. 폰 PWA랑 같은 서버 주소/토큰을 쓰면 서로 동기화됩니다.
