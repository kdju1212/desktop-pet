# Desktop Pet

Electron으로 만든 바탕화면 펫 + 할일 관리 예제입니다.

## 실행 방법

```powershell
npm.cmd install
npm.cmd start
```

## 기본 조작

- 펫 클릭: 위(북쪽)에 오늘 남은 할일이 말풍선으로 뜨고, 아래(남쪽)에 AI 버튼 2개가 같이 뜹니다. 둘 다 같은 시간 동안 떠 있다가 같이 사라집니다.
  - `화면 캡처 AI 도움`: 지금 화면을 캡처해서 AI에게 보여주고, 요약/도움말을 말풍선으로 받습니다. (Vision을 지원하는 모델이 필요합니다. 예: `gpt-4o-mini`. 이미지 입력을 지원하지 않는 모델/엔드포인트에서는 실패할 수 있습니다.)
  - `AI와 대화`: AI와 자유롭게 대화할 수 있는 작은 창을 엽니다.
- 펫 드래그: 위치를 옮깁니다.
- 펫 우클릭: 설정 메뉴를 엽니다.
- 펫 마우스 휠(가운데 버튼) 클릭: "오늘 할 일" 위젯을 엽니다. 설정창을 열지 않고도 오늘 등록된 할일을 체크/삭제/추가할 수 있습니다.

화면 캡처 AI 도움과 AI 대화는 설정 창의 `AI` 탭에서 API 키를 넣고 `AI 사용`을 켜야 동작합니다.

## 우클릭 메뉴

- `설정 열기`: 캐릭터, 말풍선, 할일, AI 설정 창을 엽니다.
- `할일 캘린더 열기`: 월별 캘린더 창을 엽니다. 날짜를 클릭하면 그 날의 할일을 카드로 보여주고 바로 수정/완료 체크/삭제할 수 있습니다.
- `데일리 할일 관리`: 매일 반복되는 할일(제목, 선택적 시간)을 등록/삭제하는 창을 엽니다. 여기 등록한 항목은 자정이 지나면(또는 앱이 켜져 있는 동안 5분마다 확인) 자동으로 그날의 할일로 새로 추가되고, 매일 새로 체크해야 합니다.
- `항상 위`: 다른 창 위에 펫을 띄울지 켜고 끕니다.
- `종료`: 앱을 종료합니다.

## 설정 창

- `캐릭터`: 이모티콘, 이미지/GIF, 외부 div 방식 중 하나를 고릅니다.
- `말풍선`: 클릭 말풍선과 알람 말풍선 지속시간을 ms 단위로 설정합니다.
- `할일`: 날짜, 시간, 제목, 메모를 직접 등록하거나 AI로 자연어 등록/수정/삭제를 합니다.
- `AI`: API 키, 모델, 엔드포인트를 설정합니다.

## 할일 파일

할일은 `schedule.json`에 저장됩니다. `done`이 `true`면 완료 처리된 항목입니다.

```json
[
  {
    "id": "sample-1",
    "date": "2026-08-23",
    "time": "15:00",
    "title": "샘플 할일",
    "memo": "선택 사항",
    "done": false
  }
]
```

완료 체크는 펫 설정창의 할일 목록 또는 할일 캘린더 창에서 체크박스로 켜고 끌 수 있습니다. 완료된 항목은 삭제되지 않고 취소선으로 표시되며, 펫을 클릭했을 때 뜨는 "오늘 남은 할일" 요약에서는 제외됩니다. 시간이 되어도 자동 알림은 뜨지 않고, 펫 클릭이나 "오늘 할 일 보기"를 눌러야 확인할 수 있습니다. (자동 알림이 필요하면 `설정` 탭의 `말풍선` > 고정 알람(`alarms`)을 대신 사용하세요.)

## AI 할일 조율

설정 창의 `AI` 탭에서 API 키를 넣고 `AI 사용`을 켠 뒤 저장하세요.

그 다음 `할일` 탭 또는 할일 캘린더 창에서 다음처럼 자연어로 입력하면 AI가 등록/수정/삭제를 알아서 판단합니다.

```text
내일 오후 3시에 병원 예약        → 새 할일 등록
병원 예약 4시로 옮겨줘           → 기존 할일 시간 수정
병원 예약 취소해줘               → 기존 할일 삭제
```

같은 날짜·시간에 이미 다른 할일이 있으면 충돌 경고 메시지가 함께 뜹니다. 할일 캘린더 창에서 날짜를 선택한 뒤 AI로 등록하면, 문장에 날짜가 없어도 선택한 날짜가 기본값으로 사용됩니다.

기본 엔드포인트는 OpenAI 호환 Chat Completions 형식입니다. Groq(무료 티어 제공)를 쓰려면 예를 들어 다음처럼 설정합니다.

```text
엔드포인트: https://api.groq.com/openai/v1/chat/completions
모델: openai/gpt-oss-20b (또는 openai/gpt-oss-120b, qwen/qwen3.6-27b)
```

API 키는 이 폴더의 `settings.json`에 평문으로 저장됩니다. 혼자 쓰는 개인 앱 기준으로만 사용하세요. 공개 배포용 앱에서는 키를 앱에 넣지 말고 서버를 따로 두는 방식이 더 안전합니다.

## 배포 메모

`.exe`로 빌드해서 배포하면 사용자 PC에는 Python이나 Node.js가 필요 없습니다.

### 자동 업데이트

`electron-updater`가 붙어있어서, 앱이 실행될 때(그리고 1시간마다) GitHub Releases를 확인해 새 버전이 있으면 자동으로 내려받고, 앱을 재시작하면 조용히 설치됩니다. 업데이트가 준비되면 펫이 말풍선으로 알려줍니다.

새 버전을 배포하는 방법은 두 가지입니다.

**방법 A: GitHub Actions로 자동 배포 (추천)**

`.github/workflows/release.yml`이 `v`로 시작하는 태그가 푸시되면 자동으로 Windows 빌드 서버에서 빌드하고 GitHub Releases에 바로 공개(publish) 상태로 올려줍니다 (`publish.releaseType: "release"`). 로컬에 Node.js가 없어도, 직접 빌드하지 않아도, 발행 버튼을 따로 누르지 않아도 됩니다.

1. `package.json`의 `version`을 올립니다 (예: `1.1.1` → `1.2.0`).
2. 커밋 후 그 버전과 같은 태그를 붙여 푸시합니다: `git tag v1.2.0 && git push origin v1.2.0` (또는 GitHub Actions 탭에서 release 워크플로를 "Run workflow"로 수동 실행)
3. GitHub Actions 탭에서 빌드가 끝날 때까지 기다리면 (1~2분) Releases에 새 버전이 자동으로 공개됩니다.

**방법 B: 로컬에서 직접 빌드**

1. `package.json`의 `version`을 올립니다.
2. GitHub에 [Personal Access Token](https://github.com/settings/tokens)을 발급받아 `repo` 권한을 준 뒤, 환경변수로 설정합니다: PowerShell은 `$env:GH_TOKEN="..."`
3. `npm run dist:publish`를 실행하면 electron-builder가 빌드 후 자동으로 GitHub Releases에 인스톨러와 `latest.yml`을 올립니다.

어느 방법이든 직접 zip을 만들어 수동으로 올리면 `latest.yml`이 없어서 자동 업데이트가 이 릴리즈를 인식하지 못합니다.

주의: 이 자동 업데이트 기능이 처음 들어간 버전(v1.1.0)부터 적용됩니다. 그 이전 버전(v1.0.0 zip)을 이미 설치해서 쓰고 계셨다면, 그 버전에는 업데이트를 확인하는 코드 자체가 없으므로 이번 한 번은 v1.1.0을 수동으로 받아서 설치해야 하고, 그 다음부터는 자동으로 갱신됩니다.

## 폰 동기화 (Cloudflare Workers + D1 + PWA)

`backend/`(Cloudflare Workers + D1 API 서버)와 `pwa/`(모바일 웹앱) 폴더가 별도로 있습니다. 구조:

- `backend/` — 할일 CRUD + 데일리 할일 API. `npm run dev`로 로컬 테스트, `npm run deploy`로 실제 배포 (Cloudflare 계정 로그인 필요: `npx wrangler login`).
- `pwa/` — 폰에서 "홈 화면에 추가"로 설치하는 웹앱. `npx wrangler deploy`로 배포.

데스크톱 펫에서 동기화를 켜려면 설정 창의 `동기화` 탭에서:
1. `동기화 사용`을 "켜기"로
2. `서버 주소`에 배포된 Workers 주소 입력
3. `API 토큰`에 `wrangler secret put API_TOKEN`으로 등록한 토큰 입력
4. `연결 테스트`로 확인 후 `저장`

동기화를 켜면 할일/데일리 할일이 로컬 `schedule.json` 대신 이 서버에 저장되고, 같은 서버 주소/토큰을 쓰는 폰 PWA와 실시간(수십 초 이내)으로 동기화됩니다. 펫 창은 30초마다 서버를 확인해서 폰에서 바뀐 내용을 반영합니다.
